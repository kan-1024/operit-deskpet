# 🐋 DeepSeek 桌宠（自用版）

自己用着顺手改的版本，基于原作者的桌宠插件～

## 加了什么

- 🔧 **修复自动加载**：重开 Operit 后它会自己出现
- 🔊 **「戳戳」音效**：戳一下会「啵」一声（自行体验）
- 🔑 **自动读取 DeepSeek API Key**：不用手填
- ✨ **优化了「戳戳」动画**：似乎更 Q 弹

## 怎么装

1. 到上面 Releases 下载 `com.deskpet-v1.0.3.toolpkg`
2. 打开 Operit → 导入插件
3. 启用「DeepSeek 桌宠」→ 对 AI 说一句「**显示桌宠**」

## 换形象 / 改台词 / 加功能（小白也能玩）

**原作者的 AI 修改手册示例**（随插件附带，叫 `AI_GUIDE.md`）～

**你要做的只是把下面的话复制给 AI** 👇

### 换形象

1. 准备一张 PNG 图片（方形、透明底更好看）
2. 把图片发给 AI，再说：

```
照 AI_GUIDE.md，帮我给桌宠换形象，用我刚发的这张图
```

### 改台词

```
照 AI_GUIDE.md，帮我把桌宠的台词改得更可爱一点
```

### 加功能

```
先读 AI_GUIDE.md 和 DESIGN.md，再帮我给桌宠加个功能：晚上自动睡觉
```

（想加什么就写什么，AI 会先读完说明书再动手，不容易改坏）
