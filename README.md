# 🐋 DeepSeek 桌宠

一只住进你手机的小鲸鱼女仆～它会挂在屏幕边上摇摇晃晃，戳一下会跳起来，还会提醒你该喝水啦。

## ✨ 它能做什么

- **陪你待机**：透明小窗口悬浮在屏幕上，摇摇晃晃，不挡事
- **戳一戳**：小鲸鱼会跳一下，还带「啵」的一声
- **会说话**：时不时冒个泡，余额变了、到点吃饭了都会念叨两句
- **管提醒**：喝水 / 休息 / 睡觉，到点就叫你（可以自己加）
- **盯余额**：自动读取你 Operit 里配好的 DeepSeek Key，余额、峰谷价随时看
- **会躲猫猫**：长按 2 秒它会先藏起来，想它了再叫出来

## 📥 怎么装

1. 下载下面的 `com.deskpet-v1.0.3.toolpkg`
2. 在 Operit 里导入它
3. 把「DeepSeek 桌宠」和它的子包「桌宠控制」打开
4. 对 AI 说一句「显示桌宠」——小鲸鱼就来啦

## 🎮 怎么跟它玩

- **戳一下**：跳一下 + 音效
- **长按 2 秒**：躲起来（还会说一句「记得让 ai 唤醒我哦」）
- **想它了**：让 AI 说「把桌宠叫出来」
- **想换形象 / 台词**：让 AI 帮忙换就行

## 💡 常见问题

- **余额显示不出来？** 让 AI 说「帮桌宠配置 API Key」。Key 只存在你自己手机上，不会上传。
- **它不出来了？** 让 AI 说「显示桌宠」；如果还不出现，重开一下 Operit 就好。
- **不想要声音？** 目前没有开关，等后续更新～
