# 🐋 DeepSeek 桌宠（修复版）

一只悬浮在手机屏幕上的小鲸鱼女仆～戳一戳会跳、会说话，还会提醒你喝水、帮你盯着 DeepSeek 余额。

> 这是**修复版**：原作者做的桌宠很棒，我们只是在上面修了几个小问题、顺手加了点小东西。

## ✨ 功能一览

- 🐳 **悬浮陪聊**：透明小窗口挂在屏幕上，摇摇晃晃，不挡事
- 👆 **戳一戳**：跳一下，还带「啵」的一声
- 💬 **会说话**：余额变化、到点喝水 / 休息，都会念叨两句
- ⏰ **管提醒**：喝水 / 休息 / 睡觉，可以自己加
- 💰 **看余额**：自动读取 Operit 里配好的 DeepSeek Key（不用手填）
- 🙈 **躲猫猫**：长按 2 秒先藏起来，想它了再叫出来

## 🔧 这个修复版改了什么？

### 修好的（都是原版的小毛病）
- **重开 Operit 后它不自动出现** → 现在自己乖乖回来
- **点击没声音** → 现在戳一下有「啵」的一声
- **点下去反应慢** → 现在按下去立刻有反馈

### 顺便优化了
- **点击会「跳一下」**（照着参考项目的 Q 弹手感调的）
- **动画更顺**：待机摇摆和弹跳分开，互不打架
- **不用手填 API Key**：自动读 Operit 里配好的 DeepSeek Key
- **换形象更稳**：图片格式不对会明确提示，不会默默失败

## 📥 怎么装（小白版）

1. 到上面的 **Releases** 下载 `com.deskpet-v1.0.3.toolpkg`
2. 打开 Operit → 找到「插件 / 工具箱」→ 导入插件 → 选刚下载的文件
   - 或者更省事：把文件发给 AI，说「**帮我安装这个插件**」
3. 装好后，把「DeepSeek 桌宠」里的「桌宠控制」打开（变成启用）
4. 完成！对 AI 说一句「**显示桌宠**」，小鲸鱼就出现啦

## 🎨 怎么换形象 / 改台词 / 加功能（重点！）

作者很贴心：插件里放了一份**「给 AI 看的说明书」**（`AI_GUIDE.md`）——里面写清楚了怎么改皮肤、改台词、加功能。

**所以你不用会写代码，会说话就行** 👇

### 换个形象（换成你喜欢的图）
1. 准备一张图片（PNG，方形，透明底最好看），放到手机里
2. 对 AI 说：
   > 「按桌宠的 AI_GUIDE.md，帮我换皮肤，图片在 /sdcard/Download/xxx.png」

   或者更简单：把图片直接发给 AI，说「**用这张图给桌宠换形象**」

### 改台词（让它说话更可爱）
> 「按 AI_GUIDE.md，帮我改桌宠的台词，把喝水提醒改得萌一点」

AI 会帮你改好台词文件，刷新一下就生效。

### 加功能 / 修东西
> 「先读桌宠的 AI_GUIDE.md 和 DESIGN.md，然后帮我给桌宠加一个功能：……」（比如「让它在晚上自动睡觉」）

说明书里要求 AI **必须先读完再动手**，所以不怕被改坏。

### 想看看它的状态？
> 「用 pet_status 看一下桌宠状态」

## ❓ 常见问题

- **余额不显示？** 跟 AI 说「帮桌宠配置 API Key」。Key 只存在你自己手机上，不会上传。
- **它不见了？** 跟 AI 说「显示桌宠」；还不行就重开一下 Operit。
- **声音能关吗？** 暂时没开关（后续考虑加）。
- **能让它少说话吗？** 可以让 AI 改台词文件，删掉不想听的或调低出现频率。
